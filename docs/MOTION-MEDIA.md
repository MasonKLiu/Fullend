## 建議工作流程

- 網頁動態：動態設計技能 → GSAP／Motion → VFX-JS。
- 3D 展示：Three.js → Theatre.js → React 後製效果／Three.quarks。
- 影片製作：Remotion 技能＋Remotion，或 HyperFrames → FFmpeg。
- 教學解說：Anatomy／Hairline／Manim → FFmpeg。
- 節拍與字幕：librosa／WhisperX → Remotion 或 HyperFrames → FFmpeg。
- AudioCraft：先核對權重授權與運算環境，再決定是否用於目標產品。
